Operator memperbarui backend VPS terlebih dahulu sesuai panduan privat, kemudian memasang installer pada akun Windows member yang sama. Tuntaskan transaksi dan laporan tertunda sebelum pembaruan. Jangan hapus atau pulihkan jurnal lama untuk melewati pemeriksaan.
